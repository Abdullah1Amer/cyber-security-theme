# Cyber Security — Claude theme

A dark-only theme for the Claude desktop and mobile apps: near-black background (#0D0D12), cards #1A1A24, your messages #232331, borders #2E2E3D, cyan accent #5CE1E6, red alerts #FF3B5C, green success #3DDC84 and amber warnings #FFB020. Claude's replies sit in a card with a red stripe on the left edge; corners are 6–8px and there are no shadows. Text uses the system sans font (medium weight) and code uses the app's code font.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install cyber-security --marketplace Abdullah1Amer/cyber-security-theme
```

Answer `y` to add the marketplace, then press Enter for the user scope.

From a shell:

```bash
claude plugin install cyber-security --marketplace Abdullah1Amer/cyber-security-theme
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `Abdullah1Amer/cyber-security-theme`, then Add plugin.

The theme draws in the desktop and mobile apps; the terminal draws no theme.
